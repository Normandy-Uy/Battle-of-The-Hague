3. LIGHTING ON THIS DEVICE — GRADE C (runtime)
================================================================================

Realtime lights: 3 (1 directional + 2 point) — still costly on Mali-G71.
No baked lightmaps shipped → GPU pays every frame.

Lighting is NOT the main killer on Aqua X; skinned meshes + RAM are worse.
Lighting Grade (Aqua X):  C


================================================================================
4. CPU ON THIS DEVICE — GRADE D
================================================================================
Helio P23 = all Cortex-A53 (efficiency cores only).
Unity 2022.3 IL2CPP + animation + physics + IMGUI OnGUI + FindObjectOfType
spam will saturate the little cores quickly.

Expected CPU bottlenecks on Aqua X:
  1. Animation / skinning jobs
  2. Main-thread render prep (MT rendering disabled)
  3. Scripts / AI Update + Find*
  4. IMGUI mobile controls
  5. Physics FixedUpdate on characters

CPU Grade for Aqua X:  D

================================================================================
10. WHAT WOULD NEED TO CHANGE TO MAKE AQUA X "OK"
================================================================================
Even with heroic optimization, Aqua X is a stretch. Minimum to reach ~25–30 FPS:
  1. Hard LOD + distance cull skinned meshes (show 1–2 hippies max on low RAM)
  2. Replace multi-mesh SimpleCitizens with 1 skinned mesh or billboard far NPCs
  3. Enable Multithreaded Rendering
  4. Cap textures to 512 on Android low tier
  5. Force 0.7 resolution scale when systemMemorySize < 3500
  6. Bake lighting; pixelLightCount = 1
  7. Replace OnGUI HUD with uGUI
  8. ARM64-only + aggressive strip
Without those, do not promise this phone.
